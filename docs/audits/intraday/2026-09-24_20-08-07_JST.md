# 2. 本轮最高优先新 P1：Sina wire 已经抓对指数，但 `Quote.code` 仍把它压回裸码，与股票共用状态键

新稳定 ID：

## `IT-P1-SINA-INDEX-QUOTE-ID-COLLIDES-WITH-STOCK-013`
**P1 latent / production-reachable when index feature is enabled and Sina serves the index route.**

HTTP wire 修好后：

```text
request: sh000001
wire:    sh000001
```

已经正确。

但当前 `SinaSource.parse_response()` 仍然：

```python
code = m.group(1)[2:]     # sh000001 -> 000001
...
Quote(code=code, ...)
```

所以 Sina 真正抓到上证指数后，交给 Engine 的仍是：

```text
Quote.code = "000001"
```

而股票平安银行的 canonical stock code 同样是：

```text
Quote.code = "000001"
```

这直接违反 `spirit_index.py` 自己的硬前提：

> 指数 Quote.code 必须自带 exchange prefix；`000001` 无法区分上证指数和平安银行。

Tencent 的 index route 已经执行这个合同：指数 `Quote.code` 保留完整 `sh000001` / `sz399001`。Sina 还没有。

### 固定触发输入

```text
股票 route 已经积累：
history["000001"] = 平安银行 5 分钟历史

随后 index route 由 Sina 服务：
sh000001 -> 正确 wire sh000001
parse -> Quote.code="000001"
```

### 根因

Source security identity 只修到了 wire/filter，没有修到业务模型 identity。

当前链为：

```text
caller security identity  sh000001
        ↓
HTTP wire                 sh000001       ✅
        ↓
Sina Quote.code           000001         ❌
        ↓
EngineState key           000001
        ↓
与 stock sz000001 共用 state/history
```

### 影响

`EngineState` 的核心价格状态仍按 `q.code` 存：
- `quotes[q.code]`
- `history[q.code]`
- `first_seen[q.code]`
- `last_price[q.code]`
- `day_open[q.code]`

所以正确抓到的指数可以覆盖 / 复用股票状态。

这与上一轮已经修掉的 route-key timestamp diagnostics 不同：时间诊断 map 已 route-key，但**核心价格/history 仍以 Quote.code 为身份**。如果指数 Quote.code 自身正确带 prefix，这些 core maps 不需要全面 route-key 化；如果 Quote.code 被压成裸码，就会重新碰撞。

# 6. 主改造：Canonical Security Identity Contract v2

这轮主改造不是继续加一个 route counter，而是先冻结**证券身份本身**。

## 6.1 Canonical identity

```text
stock route:
canonical identity = bare 6-digit code
例：600000 / 000001

index route:
canonical identity = exchange-prefixed symbol
例：sh000001 / sz399001
```

## 6.2 Identity 必须端到端稳定

同一只 index 必须在这些层全部相同：

```text
caller request
HTTP wire
raw symbol
Quote.code
SnapshotFetchResult R
SnapshotFetchResult P
SnapshotFetchResult Q/admitted key
EngineState key
SpiritIndex history key
RoundObservation requested/returned identity
```

## 6.3 Sina parser

需要 route/request role metadata。

当 route 是 index：
- response `sh000001` -> `Quote.code="sh000001"`
- `board=INDEX`

当 route 是 stocks：
- `sh600000` -> `Quote.code="600000"`
- `sz000001` -> `Quote.code="000001"`

不能为了修 index 破坏全仓 stock bare-code 兼容。

## 6.4 Detailed

对：

```text
snapshots_detailed(["sh000001"], route="index")
```

必须：

```text
requested_keys
=
raw_returned_requested_keys
=
admitted_keys
=
{"sh000001"}
```

并且：

```text
quotes[0].code == "sh000001"
```

## 6.5 Cross-source invariant

同一 index 在 Tencent 与 Sina 上必须产生同一个 canonical identity。

failover：

```text
Tencent sh000001
→ Sina sh000001
```

不得变成：

```text
Tencent sh000001
→ Sina 000001
```

完整候选：
`canonical_security_identity_contract_v2.json`。
