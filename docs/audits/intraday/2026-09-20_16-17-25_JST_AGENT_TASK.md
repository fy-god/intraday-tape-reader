## 当前优先级

### P1-最高：IT-P1-TIME-ROLE-001 / 002 / 003

目标：建立 source-epoch/time-role 时间合同。

待实现：
- `src/arad/engine.py`
- `src/arad/capabilities.py`
- 建议新增 `tests/test_source_epoch_time_contract.py`

必须先写红测：

1. **跨源首包**
   - A epoch 接受 code X ts=10:00:40；
   - serving route 切 B；
   - B 首包 X ts=10:00:05；
   - 旧 code-only watermark 应红；新 epoch 后必须被接受。

2. **同 epoch 真乱序**
   - B 首包 10:00:05 接受；
   - B 后续 10:00:01 必须拒绝。

3. **A→B→A**
   - 每次 actual serving source 切换都形成新 epoch；
   - 不能复用最早 A epoch 的硬 watermark。

4. **flat observation**
   - 同价同量的新 observation 仍必须推进 ordering state；
   - 不改变 change-only history 的既有窗口压缩行为。

5. **time role**
   - `source_time_contract.json` 中每个 source 给：
     `provider_field / role / evidence / strict_ordering_allowed / freshness_allowed`；
   - 证据不足写 `unknown`，不要猜。

6. **raw/effective/received**
   - provider_ts_raw 不得因 clamp 消失；
   - effective_event_time 与 received_at 分开。
