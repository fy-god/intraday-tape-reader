## 3. P1：零证据 / 空扫描被肯定为“全程全市场扫描”

历史稳定 ID：`IT-P2-UNIVERSE-EMPTY-SCAN-ASSERTED-AS-FULL-MARKET-001`，当前严重度 **P1**（保留旧 ID 避免漂移）。

当前新 schema 零证据：
```text
measured=False
watchlist_only_rounds=0
watchlist_only_ratio=None
ever_watchlist_only=False
```
进入 `evaluate_health` 的 positive else 分支，输出“会话期间未降级为仅自选股（全程全市场扫描）”。

最新追加已有两条产品级触发：
1. `finalize_metrics([])` 一轮未运行，却输出 positive full-market 文案；
2. active `_codes` 被清空但 `state.quotes` 仍有旧缓存时，empty scan 与 full-market 在 scope 轴不可区分。

这个缺陷的根因不是 watchlist 阈值，而是 `bool` 无法表达 scope 的第三态 / 第四态。

本轮候选改为：
```text
scope_state = full_market | watchlist_only | empty_scan | unknown
```
full-market soak：
- any `watchlist_only` -> fail；
- any `empty_scan` -> fail；
- measured=0 -> not_measured；
- 只有 measured>0 且全部 full_market 才允许肯定文案。
显式 `--watch-only` 是独立运行模式，继续豁免。

## 4. P1：session “全完整”会抹掉 t0 的明确 transport=False

新稳定 ID：`IT-P1-UNIVERSE-TRANSPORT-T0-SUPPRESSED-001`。

当前 consumer 顺序：
```text
session incomplete > 0 -> fail
session measured && incomplete==0 -> ok
否则才 fallback 到 t0
```
所以：
```text
t0 transport_complete=False
session measured=30, incomplete=0
=> universe_transport=ok
```

当前 `test_explicit_incomplete_still_fails` 设置 `rounds_transport_measured=0`，绕过了 session positive 分支，因此测试以错误理由通过。

正确 merge：
```text
t0 explicit False OR any session explicit False -> FAIL
至少一条 explicit measurement 且全部 True -> OK
全链无 explicit measurement -> NOT_MEASURED
```
后来的 positive evidence 不能抹掉同一评估窗口内的 explicit hard negative。

## 5. 本轮新 P1：mid-session active coverage 下降仍是零消费者

稳定 ID：`IT-P1-UNIVERSE-ACTIVE-COVERAGE-SESSION-BLIND-001`。

当前每轮 sample 已采 universe size、attempt/freshness/transport/age/id；`summarize_rounds()` 也已经产出：
```text
metrics["universe"] = first/last/min/max
```
但 health：
- 绝对 `universe` 读 `setup.universe_size`（t0）；
- R-12 `universe_coverage` 读 `setup.universe_truth.coverage_active`（t0）；
- session 只消费 scope / transport / freshness；
- per-round sample 没采 `expected_total / active_scan_codes / coverage_active / denominator_kind`。

固定机制：
```text
t0: 5900/6000 = 98.33%  -> OK
session: first=5900, min/last=4500
round returned/requested = 100%
transport=True
freshness=fresh
scope=full_market
```
当前 `metrics["universe"].min=4500` 已经算出，但无 consumer；`universe_coverage` 仍读 t0 98.33%，于是 75% active-market coverage 可被启动快照掩盖。

正确修复：
- per-round sample 增加 numeric active coverage evidence；
- session aggregate：`coverage_active_measured_rounds/min/p05/last`；
- final health 合并 t0 + session numeric evidence，按最坏值判；
- `round coverage` 永远不能替代 active-market coverage。

## 6. 主改造：Session Universe Evidence Contract v1

目标：把 t0 + per-round Universe 事实变成 evidence timeline，而不是“session 总是覆盖 t0”或“t0 永远覆盖 session”。

### Scope
每轮：`full_market | watchlist_only | empty_scan | unknown`。
聚合：`scope_measured_rounds / full_market_rounds / watchlist_only_rounds / empty_scan_rounds / unknown_scope_rounds`。

### Transport
合并 t0 和 session：any explicit False -> fail；measured 且 all True -> ok；no measurement -> not_measured。

### Active coverage
每轮：`expected_total / active_scan_codes / denominator_kind / coverage_active`。
聚合：`coverage_active_measured_rounds / min / p05 / last`。最终 t0 + session numeric evidence 取 worst/min。

### Freshness
沿用 `6c8` 的 session worst-state；unknown 仍为 not_measured。

### 兼容
- 旧报告无 `universe_session`：继续 `_w_ever is None`；
- legacy t0-only：允许 t0 判定，但不合成虚假 session positive。

候选合同：`session_universe_evidence_contract_v1.json`。

## 17. 最终判断

`6c8f11e` 已解决很多“producer 有事实、consumer 不读”的问题；现在暴露的是下一层：**有 consumer 仍不等于 evidence merge 正确。**

当前三个关键缺陷恰好对应三条证据逻辑：
1. 零证据不能生成肯定结论；
2. 后来的正证据不能抹掉明确 hard negative；
3. session 中途 numeric active coverage 退化不能被 t0 snapshot 永久覆盖。

下一阶段主线：
```text
Session Universe Evidence Timeline
→ Membership / Quote semantics
→ Source recovery / Timezone / ObservationInterval
→ Per-code provenance
→ Real labels
→ Factors
→ Tabular
→ TCN
```

在 evidence timeline 闭合前，增加模型训练次数不会提高结论可信度。
