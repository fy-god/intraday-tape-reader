会被「未测量」掩盖。这与 §1 的假绿**方向相反但同族**：§1 是把坏消息读成 100%，
这里是把**正常**读成「没数据」，并在真正退化时**同样**读成「没数据」。

**我定为 P2**（不是 P1），因为：(a) 重叠是**间歇**的，需要整场会话每轮都 > 1
才会彻底无样本；(b) 它不产生**错误的告警**，只是丢失诊断能力；
(c) 我**未测**真实会话中重叠态的轮次占比。

**稳定 ID**（沿用子 agent C 的提案 ID，我复核后确认可用、未与已发布 ID 冲突）：
`IT-P2-UNIVERSE-COVERAGE-OVERHANG-UNMEASURED-001`

### 7.6 修法

钳位不应按**值域**而是按**语义**判断：`coverage_active > 1.0` 是
「传输重叠」这一**已知正常原因**导致的，应当**保留数值并同时记录原因**
（例如 `coverage_active_raw=1.0181` + `coverage_overhang=true`），
而不是塌缩成 `None`。只有 `NaN`/`inf`/负数/非数值才应记 None。
（注意这**不能**改成「一律 clamp 到 1.0」—— 那会把 §1 想暴露的重叠信息抹掉，
是同一类错误的镜像。）

### 7.7 验收测试

1. **阳性**：一轮 `active_n=6020, exp=5913` ⇒ 断言 `universe_coverage_active`
   **不是 None**（当前实现给 None），且原值可得。
2. **阴性**：一轮 `active_n=5553, exp=5913` ⇒ 断言保留 `0.939117`（不得回归）。
3. **阴性 2**：`NaN`/`inf`/负数 ⇒ 断言仍记 None（三态纪律不得破坏）。
4. **会话级**：30 轮全重叠 ⇒ 断言会话轴有 30 个样本（当前为 0）。
