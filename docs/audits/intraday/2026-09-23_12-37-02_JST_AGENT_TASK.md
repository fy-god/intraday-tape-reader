## WP01 — SnapshotFetchResult v4【P1，最高优先】

统一 schema：

```text
route
source
requested_keys
raw_presence_known
raw_returned_requested_keys
quotes
rejected_quality_keys
unexpected_raw_keys
duplicate_raw_keys
raw_rows
provenance
```

Set algebra：

```text
R = requested unique identities
P = raw observed identities ∩ R
Q = usable quote identities ∩ R

returned = |P|
rejected_quality = P - Q
unknown_missing = R - P
unexpected = raw - R
```

不要按 raw row count 算 returned。
