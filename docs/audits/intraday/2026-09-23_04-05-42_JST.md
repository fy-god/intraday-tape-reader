## 2. `IT-P1-UNIVERSE-MEMBERSHIP-QUALITY-001`（P1）已得到更强的固定 SHA 证据

Eastmoney 当前已经正确建立双账：

```text
ClistPage.codes / raw_unique_codes = transport/universe 成员
ClistPage.quotes / usable_quotes   = 当前字段足以构造 Quote 的行
```

`_quote_of()` 会在代码仍有效、但 `f2/f18` 缺失、为 `"-"` 或非正时返回 `None`。所以一行可以同时满足：


`EastmoneySource.universe()` 已经计算并保存 `raw_unique_codes / usable_quotes / dropped_invalid / transport_complete / usable_coverage`，且 `transport_complete` 只按 raw transport 覆盖，不再被停牌行误伤；这一层是正确修复。

但接口最终仍：

```text
EastmoneySource.universe() -> return usable Quote[]
```

Engine 完整结果分支随后：

```python
codes = self._record_universe(quotes)
self._codes_raw = codes
```

而 `_record_universe()` 又从 `quotes` 抽 code。于是 source 层刚拆开的“transport membership”和“Quote usability”，在 active scan membership 上重新合并。

## 5. 直接工程影响：恢复交易可能存在最长一个 universe refresh interval 的监控空窗

默认配置：

```yaml
poll:
  universe_refresh_seconds: 1800
```

一只股票只是因为 universe 行当前价格无效而被删出 `_codes` 后，后续 stock snapshots 请求不再包含它。如果它在两次 universe refresh 之间恢复交易，SourceManager、current-only Snapshot、规则状态机都救不了，因为系统根本没有请求这个 code。

只有下一次 universe refresh 把它重新引入 `_codes` 后才恢复 snapshot polling。因此理论最大监控空窗可达一个 refresh interval（默认 1800 秒）。这只是配置上限推导，不是本轮实测漏报率，也没有声称真实市场发生次数。

## 6. 主改造：Universe Membership Truth Contract v1

核心不变量：

```text
market membership != current Quote availability
```

### 6.1 独立成员对象

建议新增轻量 `UniverseMember`：

```text
code
name
board
list_date
source
```

Eastmoney raw row 中这些字段可以不依赖当前价格提取。尤其 `list_date` 不能随着 Quote 不可用一起丢失；否则恢复交易后可能因为 `filters.list_dates` 缺失而按“未知放行”，制造新股过滤噪声。

### 6.2 Source 合同

兼容方案：

```text
universe()         -> 继续返回 usable Quote[]
universe_members() -> 返回 transport UniverseMember[]
```

禁止为了保存 membership 构造 `price=0` 的假 Quote；停牌、零价、缺行情、unknown 必须保持不同事实。

### 6.3 Engine 合同

完整/部分候选的 candidate size、active codes 都必须按 UniverseMember，而不是 usable Quote 数。

`state.universe` 可以继续保存 usable Quote map；Engine 单独维护 member set/list，并令 `_codes_raw` 来自 member.code。

### 6.4 UniverseTruth

至少新增：

```text
transport_member_count
usable_quotes
active_scan_codes
membership_provenance
```

`membership_provenance` 可取：

```text
transport_members
legacy_quote_projection
```

legacy source 不支持新 API 时允许兼容降级，但必须显式标注，不能冒充真正 membership truth。

## 7. 新 P2：Eastmoney 无 numeric total 时，分页“到底”仍由 Quote usability 决定

稳定 ID：`IT-P2-EASTMONEY-UNKNOWN-TOTAL-USABLE-EMPTY-STOPS-PAGINATION-001`。

当前无 total 时顺序探测：

```python
page = parse_clist_page(...)
if not page.quotes:
    break
```

因此一个页面即使有大量合法 code，只要这些行当前都无法形成 Quote，也会被当成“空页/到底”，后续页不再请求。

固定机制：

```text
page1: members100 / quotes100
page2: members100 / quotes0
page3: members100 / quotes100
```

当前在 page2 break，page3 永远不会请求。更合理的终止条件应基于 raw members / transport end，而不是 usable Quote。

本轮只列 P2：正常东财通常有 numeric total，本轮又没有完整 repo-import fixture 验证“total 缺失 + 一整页全不可用”的生产相关性。下一轮用离线 RED 很容易补强，再决定是否升级。

## 最终判断

项目已经把“transport 是否完整”和“当前 Quote 有多少可用”在 source metadata 层拆开；但真正决定预警覆盖面的第三层——“哪些 code 继续进入 snapshots polling”——仍被 Quote 是否能解析控制。

因此仓库自己已有的绿测试可以同时满足：

```text
transport 完整
10/10 新股进入
```

却仍发生：

```text
370 个老停牌成员静默退出 active scan
```

正确事实链必须是：

```text
Universe transport members
        ↓
Active scan membership
        ↓
Current snapshot availability
        ↓
Rule evaluability
```

而不是让当前价格字段决定一个证券是否还是市场成员。Membership Truth 闭合后，再进入 Source Recovery、Timezone、ObservationInterval 与真实数据/模型研究。
